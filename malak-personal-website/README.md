# ملك | Personal Portfolio

موقع شخصي من **صفحة واحدة** بتصميم Minimal Luxury، اتجاه RTL، وهوية بصرية تجمع الأسود العميق والبنفسجي الملكي والذهبي الفاخر.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً بسيطاً:

```bash
python -m http.server 5500
```

ثم افتح `http://localhost:5500`.

## هيكل المشروع

```
malak-personal-website/
├── index.html              # كل نصوص الموقع والأقسام
├── assets/
│   ├── css/
│   │   └── styles.css      # الهوية البصرية، التخطيط، الحركة، التجاوب
│   ├── js/
│   │   └── main.js         # بيانات التواصل + التفاعلات
│   └── img/
│       └── favicon.svg     # أيقونة الموقع
└── README.md
```

## بيانات التواصل

كل شيء في مكان واحد: أعلى ملف `assets/js/main.js`

```js
const SITE = {
  name: "ملك",
  email: "ooplooqalm19854@gmail.com",
  phone: "+966 57 060 3491",
  phoneHref: "tel:+966570603491",
};
```

- البريد الإلكتروني ورقم الجوال هما قناتا التواصل المعروضتان في الموقع.
- `phoneHref` هو رابط الاتصال الفعلي (بدون مسافات) المستخدم في `tel:`.
- لتغيير الاسم في عنوان الصفحة ووصفها، عدّل أيضاً `<title>` و`<meta name="description">` في `index.html`.

## تخصيص التصميم

- **الألوان والخطوط**: قسم `:root` أعلى `assets/css/styles.css`.
- **النصوص**: الأقسام موثّقة داخل `index.html`:
  - الرئيسية `#home`
  - نبذة عني `#about`
  - مهاراتي `#skills`
  - تواصل معي `#contact`
- **الصورة الشخصية**: العنصر البصري الحالي تجريدي (حرف `M` داخل إطار ذهبي). لاستبداله بصورة:
  استبدل محتوى `.art__inner` في `index.html` بصورة، مثل:

  ```html
  <div class="art__inner art__inner--photo">
    <img src="assets/img/profile.jpg" alt="صورة ملك الشخصية" loading="lazy">
  </div>
  ```

  ثم أضف في CSS:

  ```css
  .art__inner--photo { padding: 0; }
  .art__inner--photo img { width: 100%; height: 100%; object-fit: cover; }
  ```

## الميزات

- صفحة واحدة مع تنقل داخلي وتمرير ناعم.
- شريط تنقل ثابت مع تمييز القسم الحالي وقائمة للهاتف.
- ظهور تدريجي للعناصر عند التمرير (IntersectionObserver).
- شريط تقدم للقراءة، وزر نسخ للبريد ورقم الجوال، وزر العودة إلى الأعلى.
- تصميم متجاوب بالكامل + دعم `prefers-reduced-motion`.
- بدون أي مكتبات أو أطر عمل — HTML/CSS/JS فقط.
